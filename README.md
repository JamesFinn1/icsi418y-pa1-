Project Name: Task Management List

**Purposse:**
With this web application you're able to add tasks to a task list given a name and a priority level. Once you have your list you able to delete a given task or you can delete the task all together. Once a task is marked as completed it will have a green highlight to tell you the task is completed.

This web app uses HTML, CSS and JavaScript

**Instructions:**
Add a name for a task.
Select the priority level.(default is Low)
Add task to the list.
Once a task is made you can either mark it as complete or delete the task by simply pressing the buttons to the right of the task information.

**Known issues:**
Once a task is labeled as completed you will not be able to turn it back to un-compledted.
